# WeatherGPT — GitHub Pages rebuild

Fresh static rebuild for the WeatherGPT SEO project. This is not a recovered copy of the expired WordPress site.

## Deploy
1. Create a GitHub repository and upload the contents of this folder to its root.
2. Open Settings → Pages. Select Deploy from a branch, branch `main`, folder `/ (root)`.
3. Add `weathergpt.in` as the custom domain in Pages settings.
4. Configure DNS records exactly as GitHub Pages instructs; wait for verification, then enable HTTPS.

The city lookup uses Open-Meteo's public geocoding and forecast APIs. Static hosting does not include WordPress admin, PHP, database-backed forms, comments or site search. Verify GA4 and Search Console configuration before reporting them as complete.
